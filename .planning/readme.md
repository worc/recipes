The markdown files in the `.planning` directory are shared between user and agent. This is our low-budget approach to something more fully featured like [dollspace-gay's chainlink](https://github.com/dollspace-gay/chainlink) for local, small-scale project orchestration.

- `guidelines.md`: Standing conventions — how recipes get written, where things live, how the site gets built. Read this first.
- `ideation.md`: Unprioritized thoughts, plans, prospective designs and the like
- `next-time.md`: Hand-off notes from the previous session, work that is immediately ready for implementation
- `over-the-horizon.md`: Long-term goals and the general vision and design of the project
- `human-do-this.md`: Operator-side checklist for things that need the registrar, root on Altair, or anything else outside the agent's sandbox

Related: the "Recipe Book" project in Claude is the research and conversation side of this repo. This repo is the source of truth for finished recipes.
